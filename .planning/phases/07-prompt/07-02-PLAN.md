<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser -> analyze route | User-controlled ids, slot and operation key cross authentication/input validation. |
| Task payload/media -> Worker process | Database data and stored media become CLI input but must not become shell syntax. |
| Codex stdout/stderr -> database/log/API | Untrusted model/process output may contain malformed data, secrets, paths or oversized content. |
| Worker replicas -> Redis lease | Multiple processes contend for one global image concurrency limit. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-05 | Tampering | Codex process invocation | critical | mitigate | Fixed executable/argv, `shell:false`, stdin prompt, controlled temp files and strict Zod final-output validation. |
| T-07-06 | Information Disclosure | stderr/raw output/Task projection | high | mitigate | Byte caps plus centralized redaction of secrets, signed URLs and absolute paths before logs/errors; authorized raw result only. |
| T-07-07 | Elevation of Privilege | analyze route/payload ids | high | mitigate | Project auth and server-side Shot/source/media lookup; recompute fingerprint and ignore executor/caller relationships. |
| T-07-08 | Denial of Service | image Codex concurrency | high | mitigate | Atomic Redis lease limit 3, expiry/renewal/release, bounded process timeout and output bytes. |
| T-07-09 | Spoofing | Codex session provenance | medium | mitigate | Parse one session id from one process event stream; session metadata never grants auth or approval. |
</threat_model>
