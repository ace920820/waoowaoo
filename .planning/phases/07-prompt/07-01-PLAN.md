## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-01 | Tampering | `persistVideoPromptRunAtomically` | high | mitigate | Strict Zod output, exact stable-id set, ownership/current-revision lookup and one transaction before any version write. |
| T-07-02 | Elevation of Privilege | review/adoption service | high | mitigate | Resolve project -> Shot -> track -> version ownership server-side; never trust caller-provided relationships. |
| T-07-03 | Tampering | adopted Prompt after upstream edits | high | mitigate | Input fingerprint plus append-only invalidation records; downstream gate rechecks validity instead of reading latest. |
| T-07-04 | Repudiation | human approval | medium | mitigate | Persist reviewer id/time, prior version, adopted pointer and immutable provenance for every approval. |
</threat_model>
