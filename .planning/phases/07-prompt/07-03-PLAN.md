<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser -> track API | Track/version ids, edits and adoption commands cross auth/access validation. |
| Stored model output -> React UI | Long untrusted raw/model text is rendered to the user. |
| Client cache -> business review state | React Query cache must not become an approval/adoption authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-10 | Elevation of Privilege | track history/edit/adopt route | high | mitigate | Resolve authenticated project ownership and track/version ancestry for GET/POST/PATCH; cross-project ids return not found. |
| T-07-11 | Tampering | client approval/adoption state | high | mitigate | Server transaction is sole writer; mutations invalidate/refetch and UI never infers approval from Task completion. |
| T-07-12 | Information Disclosure | snapshot/full raw output | high | mitigate | Snapshot is allowlisted/bounded; full output requires authorized per-track fetch and excludes commands, env, storage keys and stderr. |
| T-07-13 | Tampering | model output rendering | medium | mitigate | Render as text/structured React nodes, never `dangerouslySetInnerHTML`; bound long content and preserve safe expansion. |
</threat_model>
