# Phase 8 Plan 07：场景 / 角色 / 物品资产选择器

## 目标

把语义层的场景和角色从文本输入改成经典分镜页那种资产选择器布局，再加一个物品选择区。用户可以直接点击选择，不再手输名字。

## 依赖

- Plan 05 的语义面板
- 已有的项目场景/角色/物品资产系统
- 经典分镜页（novel-promotion）中的资产选择组件和查询方式

## Task 1：场景资产选择器

把场景文本输入改为：

- 下拉选择项目已有场景资产
- 第一项："跟随项目默认（场景名）"
- 其余项：项目中所有场景
- 下方显示当前生效来源："跟随默认场景"或"本镜头单独指定"
- 支持取消当前选择（回到跟随默认）
- 场景缺失/未绑定时：显示"未绑定场景，可继续生成"

需要复用：
- 场景资产查询（global_locations / 项目级场景）
- 经典分镜页的场景下拉交互模式

### 验证

- 下拉能列出场景
- 选择后 sceneAssetId 写入服务端
- 选择空值回到跟随默认
- `npm run typecheck`

## Task 2：角色资产 Chip 多选

把角色文本输入改为：

- 可点击的角色 Chip 列表（多行）
- 已选角色高亮
- 点击切换选中状态
- 显示当前已选数量
- 支持"覆盖系统预选"提示
- 角色来自项目角色资产，带缩略图或至少名称 + 描述

需要复用：
- 角色资产查询
- 角色 Chip / Tag 组件
- 经典分镜页角色选择交互

### 验证

- 点击选中/取消
- 已选角色 ID 数组写入服务端
- 空状态显示"未绑定角色，可继续生成"
- `npm run typecheck`

## Task 3：物品（Props）资产 Chip 多选

新增物品选择区，布局跟角色一致：

- 可点击的物品 Chip 列表
- 多选
- 来自项目 Props 资产
- 空状态显示"未绑定物品，可继续生成"
- 提示："物品缺失时仍允许生成，由 Prompt 描述补足"

需要复用：
- Props 资产查询
- 同样的 Chip 多选交互模式

### 验证

- 多选/取消正常
- propAssetIds 写入服务端
- 空状态提示正确
- `npm run typecheck`

## Snapshot 透出

每个资产除了 ID 还要透出：
- 名称（label / name）
- 缩略图 URL（如果有）
- 绑定来源（默认 / 镜头单独指定）

## 验收

- [ ] 场景下拉选择，显示生效来源
- [ ] 角色 Chip 多选，点击切换
- [ ] 物品 Chip 多选，新增区域
- [ ] 都用资产 ID 存储，不存名称
- [ ] 缺失时给出提示但不阻塞
- [ ] 复用现有资产组件，不重复造轮子
- [ ] typecheck 通过
