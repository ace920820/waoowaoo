# 08-08: 画面描述 Prompt 编辑 + 经典生成卡片交互

## 目标
修复两个 UI/交互缺陷：
1. 将当前选中 Start/Middle/End 的图片 Prompt 移入「镜头语义 > 画面描述」，支持直接编辑、保存即采用。
2. 恢复新画面卡片的经典分镜交互：空卡显示「待生成 + 生成图片」按钮，悬浮显示底部浮窗（候选数量、重新生成、查看数据），不再依赖手工模型输入。

## 任务

### Task 1: 画面描述 Prompt 编辑与自动采用
**文件：**
- `src/app/[locale]/workspace/[projectId]/modes/remake/storyboard/ShotSemanticsPanel.tsx`
- `src/lib/remake-projects/prompt/service.ts`
- `src/app/api/remake-projects/[projectId]/prompts/tracks/[trackId]/route.ts`

**行为：**
- 「画面描述」字段改为显示当前选中帧（start/middle/end）的图片 Prompt 当前采用版本的 coreText。
- 原 semantics.description 保留并改名为「镜头语义描述」，避免丢失人工语义数据。
- 编辑保存时调用 Prompt track 的 human-edit 接口，创建新 revision 后自动批准并采用（原子化，失败不改变旧版本）。
- Prompt 状态区域保留版本号、状态、来源和「前往 Prompt 页」，不再重复完整文本。
- 视频 Prompt 不受图片帧切换影响，保持独立。

### Task 2: 经典新画面卡片交互
**文件：**
- `src/app/[locale]/workspace/[projectId]/modes/remake/storyboard/RemakeStoryboardStage.tsx`
- `src/lib/remake-projects/keyframes/service.ts`
- `src/app/api/remake-projects/[projectId]/shots/[shotId]/keyframes/generate/route.ts`
- 参考：经典分镜 ImageSection.tsx, ImageSectionActionButtons.tsx

**行为：**
- 空新画面卡显示「待生成」和「生成图片」按钮，不因前端 model 为空而隐藏。
- 每张新画面卡为 group，悬浮时底部浮窗显示：候选数量选择、生成/重新生成、查看生成数据。
- 生成中展示 Task 状态，禁止重复提交。
- 未勾选「用于生成」时点击生成给出明确提示，不触发生成。
- 移除 Remake 页面底部手工模型输入框；model 改为可选，服务端从项目 storyboardModel 解析。
- 优先级：显式 model > 项目 storyboardModel；项目未配置时返回可读错误。
- 所有生成复用现有 Remake keyframe task、候选批次、预览、下载、采用和历史记录服务。

## 测试
- Prompt track API：编辑后生成新版本 + 自动批准采用；失败不改变既有采用版本
- Keyframe 生成 API：缺省 model 时使用项目 storyboardModel；未配置时返回错误；显式 model 优先
- 组件：切换原始帧后「画面描述」同步更新；空新画面卡显示生成按钮；悬浮浮窗
- Playwright：编辑保存后刷新仍显示新 Prompt；空卡点击生成触发任务；响应式
