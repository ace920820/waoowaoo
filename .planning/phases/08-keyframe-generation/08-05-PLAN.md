# Phase 8 Plan 05：2×3 布局 + 逐槽 Prompt + 原始帧选择

## 目标

把当前 Remake 分镜页从"原始帧列表 + 独立新画面区"的结构，改为"2 行 3 列的对齐分镜工作台"：上排是原始动作参考，下排是新画面参考，严格按 Start / Middle / End 对齐。点击任何一帧切换"当前查看"状态，下方 Prompt 和语义信息随当前帧刷新。点击图片不改变"用于生成"选择，两个动作完全独立。

## 依赖

Phase 8 Plan 04 已有的 Remake 分镜页结构、keyframe adapter、Shot 语义字段。

## Task 1：视图模型层 —— 2×3 布局 + 逐槽 Prompt

在 `src/lib/remake-projects/keyframes/adapter.ts` 中新增两个纯函数：

- `buildSourceSlotView(shot, slot)` — 对单个槽位返回：原始帧、是否选中生成、eligibility、对应 image Prompt 摘要（版本号、状态、核心文本）
- `buildTwoRowLayout(shot)` — 返回 3 列，每列包含上下两行：原始帧 + 新画面对象（采用状态、候选数、批次、空状态）

这两个函数都是纯的，不依赖 React，可以直接单元测试覆盖。

### 验证

- `npx vitest run tests/unit/remake-projects/remake-keyframe-source-selection.test.ts`
- `npx vitest run tests/unit/remake-projects/remake-keyframe-2row-layout.test.ts`
- 列顺序必须稳定，不受内部 track 数组顺序影响
- 视频 Prompt 不能出现在逐槽 image prompt 中

## Task 2：UI 层 —— 2×3 Shot 工作区

重写 `RemakeStoryboardStage.tsx` 中的 `ShotBlock` 布局：

1. 原来的"原始动作参考"区 + "新画面参考"区 → 合并成一个 2×3 网格
2. 行标签保留：上排 `原始动作参考`、下排 `新画面参考`
3. 列固定：Start / Middle / End
4. 点击上排原始帧 → 切换当前选中帧（selectedSourceSlot state）
5. 当前选中帧有明显高亮边框 + 状态 chip
6. 每格下方保留"用于生成"复选框，点击复选框不影响选中帧
7. 下排新画面对应每列显示：采用缩略图、候选数、批次、生成状态
8. 没有生成槽位的列显示空状态卡，保持布局稳定

### 验证

- 视觉上是 2 行 3 列
- 点击原始帧只改变选中状态，不改变 checkbox
- 选中的帧有清晰视觉标识
- `npm run typecheck` 通过
- `npm run check:locale-navigation` 通过

## Task 3：语义层 —— 逐帧 Prompt + 人工描述拆分

把 `ShotSemanticsPanel.tsx` 中的信息区按当前选中帧动态刷新：

1. `画面描述` 改名为 `当前帧 Prompt`，只读显示已采用图片 Prompt 的完整文本 + 版本号 + 状态
2. 原来的 `画面描述` 输入框改名为 `镜头语义描述`（人工可编辑的主体动作/环境/叙事补充）
3. Prompt 状态卡保留 4 格（Start/Middle/End 图片 + 视频），当前选中的那一格高亮
4. 增加"在 Prompt 页编辑"链接，跳转到 `?stage=prompt&shot=<id>`
5. 视频 Prompt 始终单独显示，不随 Start/Middle/End 选择而改变内容

### 验证

- 选中不同帧 → 显示的 Prompt 文本不同
- 视频 Prompt 内容恒定，不随帧切换变化
- 没有已采用版本时显示"暂无已采用 Prompt"
- `npm run typecheck` 通过

- [ ] 点击原始帧切换选中，不改变"用于生成"勾选

- [ ] 画面描述显示当前帧的已采用 Prompt，而不是空文本框
- [ ] 视频 Prompt 单独显示，不混入图片逐槽 Prompt
- [ ] 空状态卡保持布局稳定，不跳列
