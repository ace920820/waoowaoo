## 短镜头兜底策略

| Option | Description | Selected |
|--------|-------------|----------|
| 允许单独生成兜底（拉长到最短档） | 短镜头可以不进 unit，单独生成时按现有逻辑拉长到最短档（4s）。用户可选，不强制合并。 | ✓ |
| 必须进 unit | 短镜头必须并入 unit，否则阻止视频生成，保证所有翻拍视频时长真实。 | |
| 默认合并、可兜底 | 默认建议合并，但用户可手动切到单独生成兜底。 | |

**User's choice:** 允许单独生成兜底（拉长到最短档）
**Notes:** 第二个问题确认 UI 明确标注"拉长到最短档"；第三个问题确认兜底提示词不声明原时长 vs 生成时长（保持简单）。

## 同构判定阈值

| Option | Description | Selected |
|--------|-------------|----------|
| 加权评分 | sceneTag 相等 + characterTags 交集比例加权，阈值 ≥0.6 算同构。 | |
| 只看场景标签 | 只要 sceneTag 相同就算同构。 | |
| 只看角色交集 | 只要 characterTags 有交集就算同构。 | |

**User's choice:** 自定义回复 — "不再考虑同构这个点了，全部由手动操作镜头合并为 unit"
**Notes:** 用户明确取消了原决策 3（优先同构相邻镜头合并）。后续确认：合并完全手动，系统不做同构建议，但保留"镜头过短需并入相邻镜头"的时长提示引导。sceneTag/characterTags 仅作为展示信息，不参与合并逻辑。
