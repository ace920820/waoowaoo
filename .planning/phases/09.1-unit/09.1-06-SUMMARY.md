# Phase 09.1 Plan 06: 成片页 unit 模式 Summary

**One-liner:** 成片页完成合并 unit 交互——任意勾选镜头、WYSIWYG 预览、unit 版本闭环、由 unit 交付状态与短镜头标注。

## Accomplishments

1. **snapshot 投影**：`getRemakeProjectSnapshot` 增加 `units`（id/userLabel/members（ordinal/shotId/sequence/label/durationSeconds）/track（adoptedVersionId/batches/versions）/actionSheets），`RemakeSnapshot` 类型增加可选 `units` 字段。
2. **unit 模式入口（D-14/D-15）**：成片页 header 加"合并 unit 模式"toggle；选择模式按勾选顺序编号（任意组合、无相邻限制、无同构逻辑）；≥2 镜头可创建 unit 进入视图。
3. **短镜头标注（D-11/D-12/D-20）**：单 shot 卡片显示"镜头过短"提示（无自动合并建议）与"拉长到最短档"徽标；提示词路径未改动（D-13）。
4. **client-safe adapter**：`adaptRemakeUnit`（成员/时长/track/版本/冻结状态）+ `buildShotToUnitMap`（shot→unit 映射）。
5. **unit 预览面板（D-16）**：`RemakeVideoUnitPanel` 用 `buildUnitSubmissionPreview`（与服务端冻结同一纯函数）渲染 WYSIWYG 预览；成员可重排/移除（提交前），pending 任务或已提交 batch 后冻结（D-19）。
6. **unit 版本闭环（D-17）**：版本列表播放/采用（替换确认）/备注/重新确认，invalidation 复核状态展示。
7. **由 unit 交付（D-18）**：成员卡片显示状态芯片，生成按钮替换为"查看所属 unit"跳转。
