# Phase 09.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Client -> pure contract layer | Untrusted member selections, timecodes, and prompt text enter the frozen snapshot/fingerprint boundary. | Member ids, timecodes, prompt text |
| DB adopted-keyframe/media rows -> reference plan | Adopted media identities cross into the provider-bound reference plan. | Media refs, asset ids |
| Sharp render inputs -> composite buffer | Member frame buffers are composited into the merged action sheet. | Member frame buffers |
| API/service -> unit tables | Member sets, ordinals, and freeze state cross into durable storage. | Member sets, ordinals |
| Worker append -> outputVersion/provenance | Generated media evidence and provenance cross the persistence boundary. | Batch/version rows, provenance |
| Browser -> unit API routes | Member ids, operation keys, and options enter project-scoped submission logic. | Member ids, operation keys |
| Submission service -> task payload | The frozen unit snapshot (with the deferred merged-sheet entry) crosses into the enqueued task payload. | Frozen unit snapshot |
| Task payload -> video worker/provider/storage | The frozen unit snapshot crosses async execution and the external provider/storage boundary. | Frozen snapshot, media refs |
| Worker -> merged-sheet storage | Member keyframe buffers are composited, uploaded, and persisted inside the task flow. | Composite buffer, provenance |
| Browser UI -> unit API | Selection order, member edits, notes, and adopt actions cross to the server. | Notes, selections, adopt actions |
