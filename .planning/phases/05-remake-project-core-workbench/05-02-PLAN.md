## Trust Boundaries

| Boundary | Description |
|---|---|
| 浏览器 -> remake snapshot/Shot routes | projectId、shotId、requestId、Unicode 名称、reviewStatus 与 revision 均不可信 |
| Route -> domain service | route 已认证身份进入只接受解析后 DTO 的事务服务 |
| Domain service -> immutable history | 并发/晚到写入可能污染 revision、输出与 provenance 顺序 |
