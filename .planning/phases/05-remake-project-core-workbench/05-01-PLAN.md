## Trust Boundaries

| Boundary | Description |
|---|---|
| 浏览器 -> `/api/projects` | 不可信项目类型、名称、creationRequestId 与重复提交进入创建事务 |
| 浏览器 -> 翻拍 Project/Shot API | 不可信 projectId/shotId/body 跨越项目所有权边界 |
| API -> Prisma/MySQL | Project、Shot、Task、GraphRun、输出与 provenance 必须原子提交并保持历史 |
| Prisma Task/Run -> 工作台 DTO | 可能含执行上下文的内部记录被投影到用户界面 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-05-01 | Spoofing / Elevation | remake project/Shot routes | high | blocked_until_verified | 创建用 `requireUserAuth`，所有已有 projectId 的路由先调用 `requireProjectAuthLight`，再按 projectId+shotId 查询；真实 DB tracer 覆盖未授权与跨项目访问。 |
| T-05-02 | Tampering | create/PATCH body | high | blocked_until_verified | type、UUID、名称、审核状态和 expectedRevision 使用白名单解析；事务内乐观并发与唯一键拒绝越权字段、重复提交和丢失更新。 |
| T-05-03 | Repudiation / Tampering | revision/output/provenance | high | blocked_until_verified | revision/output/provenance 追加写，失效只更新 review 标记；Task/GraphRun、输入版本、执行标识和 output version 可追溯。 |
| T-05-04 | Denial of Service | concurrent creates/updates | medium | mitigate | creationRequestId、复合唯一约束、expectedRevision 和有界事务重试消除重复行与无限竞争。 |
| T-05-05 | Information Disclosure | snapshot/UI projection | high | blocked_until_verified | snapshot 使用字段 allowlist 与 `normalizeTaskError`，不序列化 payload/result/billingInfo、命令、Session、env、secret 或 raw log。 |
