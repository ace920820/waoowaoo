## 模型实际输入的选择方式

| Option | Description | Selected |
|--------|-------------|----------|
| 自动配好，可手动调整 | 系统按模型能力预选，用户可调整 | |
| 完全自动，不让用户调整 | 系统决定全部输入 | |
| 每次都由用户手动选择 | 用户每次明确选择实际发送的多图输入 | ✓ |

**User's choice:** 使用的模型都支持多图；每次生成都由用户手动选择实际图片。
**Notes:** 提交前必须展示实际会传的图片，不能静默丢图；每个视频版本必须能查看完整参考图片和完整提示词。

## 可选参考图片范围

| Option | Description | Selected |
|--------|-------------|----------|
| 新关键帧和动作表 | 使用已采用新关键帧与原始三帧动作表 | ✓ |
| 新关键帧和原始三帧 | 原始帧以单图进入候选池 | |
| 全部可选 | 新关键帧、原始三帧与动作表全部进入候选池 | |

**User's choice:** 新关键帧和动作表。
**Notes:** 原始三帧单图不重复提供。

---

## 最低输入门槛

| Option | Description | Selected |
|--------|-------------|----------|
| 至少一张新关键帧，动作表可选 | 新画面负责视觉，动作表仅辅助 | ✓ |
| 新关键帧和动作表都必选 | 每次必须同时提供两类输入 | |
| 任意一项即可 | 允许只传动作表 | |

**User's choice:** 至少一张新关键帧，动作表可选。
**Notes:** 只选择动作表不得提交。

---

## 图片输入顺序

| Option | Description | Selected |
|--------|-------------|----------|
| 默认排序，允许拖动调整 | 默认 Start/Middle/End/动作表，用户可重排 | |
| 固定顺序，不允许调整 | 未选择项跳过，其他项保持稳定顺序 | ✓ |
| 按勾选顺序 | 用户点击顺序就是模型输入顺序 | |

**User's choice:** 固定顺序，不允许调整。
**Notes:** 固定为 Start 新关键帧、Middle 新关键帧、End 新关键帧、动作表。

## 参数默认值与单次覆盖

| Option | Description | Selected |
|--------|-------------|----------|
| 带出项目默认，每次可改 | 每个 Shot 继承项目配置，单次覆盖不回写项目 | ✓ |
| 每次重新填写 | 不继承项目默认 | |
| 全部项目固定 | 单个 Shot 不允许覆盖 | |

**User's choice:** 参考现有多镜头视频生成参数填入模式；每个镜头带出项目默认，每次允许修改。
**Notes:** 包括模型、Omni/全能参考模式、音频、分辨率和其他模型能力参数。

---

## 默认生成时长

| Option | Description | Selected |
|--------|-------------|----------|
| 匹配原 Shot 时长 | 从原镜头时长计算，并允许用户修改 | ✓ |
| 使用项目默认时长 | 不参考原镜头 | |
| 每次必须手选 | 不提供时长默认值 | |

**User's choice:** 优先匹配原镜头时长，受模型最短时长和 15 秒上限约束。
**Notes:** 原镜头时长先向上取整到整数秒；低于模型最短时长时补到最短，高于 15 秒时限制到 15 秒。

---

## 离散时长档位

| Option | Description | Selected |
|--------|-------------|----------|
| 向上选最近合法档位 | 避免生成时长短于原镜头动作 | ✓ |
| 选择最接近档位 | 可能向下缩短 | |

**User's choice:** 向上选最近合法档位。
**Notes:** 若模型最大时长低于 15 秒，以模型实际最大时长为上限。

---

## 版本比较与采用

**User's choice:** 按 the agent 推荐方案做轻量 MVP，减小首版工作量并逐步迭代。
**Notes:** 原片和版本分别播放；默认当前采用版本，历史按时间排列；一段简单审核备注；显式采用和替换确认；暂不做同步双播放器、自动评分、排名或自动采用。

---

## 上游变化后的处理

**User's choice:** 按 the agent 推荐方案做轻量 MVP，减小首版工作量并逐步迭代。
**Notes:** 冻结旧版本完整输入；上游变化后旧视频保留并标记需复核；保留采用指针但 Shot 不再算完成；允许重新确认旧版本或生成并采用新版；暂不自动重生成或新增复杂依赖图。
