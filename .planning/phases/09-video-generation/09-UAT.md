# Phase 09 UAT: 翻拍视频生成与版本管理

## Status: pending

## 前置条件

- [ ] 项目已创建，原视频已导入，镜头分析完成
- [ ] 至少一个 Shot 的 Video Prompt 已批准
- [ ] 至少一个 Shot 的 Start / Middle / End 三帧关键帧已生成并采用
- [ ] 项目配置中已选择视频模型
- [ ] 浏览器中登录有效账号，进入项目成片页

## 验收用例

### UC-01: 手动选择参考图片（D-01~D-05）

**步骤：**
1. 进入翻拍项目 → 成片阶段
2. 找到一个有三帧已采用画面的 Shot

**预期：**
- [ ] Start / Middle / End 三个槽位均以缩略图按钮形式呈现
- [ ] 默认无选中（按钮均为未选中态）
- [ ] 点击 Start 按钮 → 选中（高亮/边框变化）
- [ ] 点击 End 按钮 → 选中
- [ ] 展开"实际输入预览" → 图片按 Start → End 顺序编号展示（Middle 未选中故跳过）
- [ ] 顺序固定，不可拖拽调整

### UC-02: 动作表可选参考（D-02 / D-03）

**步骤：**
1. 勾选动作表 checkbox
2. 展开实际输入预览

**预期：**
- [ ] 动作表出现在预览末尾（编号在关键帧之后）
- [ ] 仅勾选动作表、不选任何关键帧时，"视频生成"按钮禁用，并提示"请至少选择一张已采用的新关键帧"

### UC-03: 模型与参数控件（D-07~D-11）

**步骤：**
1. 查看"生成参数"区域
2. 切换不同视频模型

**预期：**
- [ ] 默认选中项目配置中的视频模型
- [ ] 展示时长、分辨率、生成音频等参数选项
- [ ] 参数选项仅展示当前模型支持的值
- [ ] 切换模型后，不兼容的参数被替换为新模型的默认值
- [ ] 默认时长约等于原 Shot 时长（向上取整，受模型能力约束）
- [ ] 修改参数不影响项目默认配置（刷新后恢复为项目默认）

### UC-04: 生成视频（VGEN-01 / VGEN-03 / VGEN-04）

**步骤：**
1. 选择 1~3 张已采用关键帧（可选动作表）
2. 选择模型和参数
3. 点击"视频生成"

**预期：**
- [ ] 按钮变为"生成中…"状态
- [ ] 生成成功后，版本历史中出现新版本缩略图
- [ ] 视频可播放
- [ ] Task 状态正确（queued → processing → completed）
- [ ] 计费记录正确产生（如有）

### UC-05: 版本历史与播放（D-13 / D-16）

**步骤：**
1. 生成 2 个不同版本
2. 点击不同版本缩略图

**预期：**
- [ ] 版本按时间倒序排列（最新在前）
- [ ] 已采用版本标有绿色"当前"角标
- [ ] 点击版本切换右侧播放器内容
- [ ] 点击播放/浏览历史不会改变采用指针
- [ ] 原始视频和生成视频各自独立播放，无同步联动

### UC-06: 审核备注（D-14）

**步骤：**
1. 选择一个版本
2. 在备注框中输入文字
3. 点击"保存备注"

**预期：**
- [ ] 备注保存成功
- [ ] 刷新页面后备注仍在
- [ ] 备注为纯文本，无结构化评分/标签

### UC-07: 采用与替换（D-15）

**步骤：**
1. 选择一个非当前采用的版本
2. 点击"采用此版本"

**预期：**
- [ ] 首次采用：直接成功，版本标上"当前"角标
- [ ] 替换采用：弹出确认对话框"确认替换当前采用版本？"
- [ ] 点击取消：不替换，保持原采用版本
- [ ] 点击确认替换：替换成功，新版本标"当前"
- [ ] 旧采用版本仍保留在历史中

### UC-08: 上游变化失效（D-17 / D-18）

**步骤：**
1. 有已采用的视频版本
2. 修改上游关键帧（重新生成并采用新的关键帧）
3. 回到成片页

**预期：**
- [ ] 旧视频版本标有"需复核"（琥珀色）标记
- [ ] 已采用版本保留采用指针（不会自动撤销采用）
- [ ] 但 Shot 状态不再视为"已完成/就绪"

### UC-09: 重新确认（D-19）

**步骤：**
1. 选中一个已失效的采用版本
2. 点击"重新确认（继续采用）"

**预期：**
- [ ] "需复核"标记消失
- [ ] 版本恢复为正常采用状态
- [ ] 采用指针不变

### UC-10: 操作幂等性

**步骤：**
1. 使用相同 operationKey 连续提交两次生成请求

**预期：**
- [ ] 第二次提交幂等，不创建重复批次/任务
- [ ] 或返回错误提示重复操作（根据实现）
