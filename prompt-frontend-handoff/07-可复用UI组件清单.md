# 可复用 UI 组件清单（AI 优先复用，禁止重造）

> 位置：`src/components/ui/`。这些是项目现有设计系统组件，**优先 import 使用**。
> 示例 import：`import { GlassButton } from '@/components/ui/primitives'`

## 1. primitives（玻璃态基础组件）— `src/components/ui/primitives/`

| 组件 | 用途 |
|---|---|
| `GlassButton` | 玻璃按钮（主/次/危险变体） |
| `GlassChip` | 标签/徽章（如状态标签：待审核/已批准） |
| `GlassField` | 表单字段容器 |
| `GlassInput` | 文本输入框 |
| `GlassTextarea` | 多行文本域（**Prompt 正文编辑必用**） |
| `GlassModalShell` | 模态框外壳（查看完整分析弹层用） |
| `GlassSurface` | 玻璃卡片容器 |

## 3. 现有工作台的组件引用方式（照抄）

从 `02-现有工作台骨架.tsx` 可以看到现有用法：
- `import { SceneDetectStageHost } from './scenedetect/SceneDetectStageHost'`（阶段组件挂载方式）
- `import './scenedetect/scenedetect-stage.css'`（阶段级 CSS 命名：`remake-*` 前缀）

- 组件：`PromptStage.tsx` + `prompt-stage.css`（CSS 类名用 `remake-prompt-*` 前缀，和现有 `remake-*` 保持一致）
