# 设计系统与视觉风格（AI 必须遵守）

> 参考文件：`src/app/globals.css`（522 行）+ `src/styles/ui-tokens-glass.css` + `src/styles/ui-semantic-glass.css`。
> 整体风格：**浅色、玻璃态（Glassmorphism）、黑白灰极简**。截图见 `08-截图/`。

## 1. 颜色（CSS 变量，来自 globals.css）

| 变量 | 值 | 用途 |
|---|---|---|
| `--background` | `oklch(1 0 0)`（纯白） | 页面背景 |
| `--foreground` | `oklch(0.145 0 0)`（近黑） | 主文字 |
| `--bg-primary` | `var(--glass-bg-canvas)` | 浅灰画布背景（**注意：画布不是纯白，是浅灰**） |
| `--bg-card` | `var(--glass-bg-surface)` | 卡片白色 |
| `--bg-glass` | `var(--glass-bg-surface-strong)` | 玻璃态背景 |
| `--primary` | `oklch(0.205 0 0)`（近黑） | 主按钮/强调（**黑色主按钮，不是蓝色**） |
| `--primary-foreground` | `oklch(0.985 0 0)`（白） | 主按钮文字 |
| `--secondary` / `--muted` / `--accent` | `oklch(0.97 0 0)`（浅灰） | 次要背景 |
| `--muted-foreground` | `oklch(0.556 0 0)`（中灰） | 次要文字 |
| `--destructive` | `oklch(0.577 0.245 27.325)`（红） | 删除/错误 |
| `--border` / `--input` | `oklch(0.922 0 0)`（浅灰边框） | 边框/输入框 |
| `--ring` | `oklch(0.708 0 0)`（灰） | 焦点环 |
| `--chart-1..5` | 彩色（橙/青/蓝/黄/粉） | 图表（Prompt 阶段大概率用不到） |

## 2. 圆角 / 阴影 / 模糊（玻璃态核心）

| 变量 | 用途 |
|---|---|
| `--radius-card: var(--glass-radius-md)` | 卡片圆角 |
| `--radius-button: var(--glass-radius-sm)` | 按钮圆角 |
| `--radius-input: var(--glass-radius-xs)` | 输入框圆角 |
| `--shadow-card: var(--glass-shadow-sm)` | 卡片阴影（轻） |
| `--shadow-card-hover: var(--glass-shadow-md)` | 卡片 hover 阴影 |
| `--shadow-glass: var(--glass-shadow-lg)` | 玻璃/浮层阴影 |
| `--blur-glass: var(--glass-blur-lg)` | 玻璃模糊（浮层/抽屉背景） |

## 3. 字体

- 中文：默认系统字体（Geist Sans 为西文），`--font-sans: var(--font-geist-sans)`、`--font-mono: var(--font-geist-mono)`
- 不要引入新字体

## 4. 现有页面结构（截图对照）

- **顶部导航**：白色导航栏，左侧 logo「waoowaoo」+ 版本标签「Beta v0.4.1」，右侧登录/注册/语言选择器（截图 01）
- **工作台内**（截图 02-04）：
  - `remake-project-bar`：项目标题栏（eyebrow 小字 + 标题 + 描述 + 任务按钮）
  - `remake-stage-nav`：阶段导航（横排按钮，当前项 `is-active` 高亮）
  - `remake-stage-main`：阶段内容区
  - `remake-task-overlay` + `remake-task-drawer`：任务抽屉（半透明遮罩 + 右侧玻璃抽屉）

## 5. 风格要点（AI 生成时自查）

- ✅ 浅色、留白充足、玻璃卡片、圆角适中、阴影轻
- ✅ 主按钮黑色（近黑）底 + 白字；次要操作用浅灰底
- ✅ 中文文案，简洁直白
- ❌ 不要彩色渐变背景、不要炫光、不要大面积品牌色
- ❌ 不要新造组件库——用 `07-可复用UI组件清单.md` 里的 Glass 组件
